# flask-analytics
Мини-счётчик посещений для сайтов. Вставляешь скрипт на свой сайт — и он начинает считать просмотры страниц, уникальных посетителей и собирать статистику по дням. Есть дашборд, где можно посмотреть все данные. Сделано, чтобы понять, как работают трекинг-системы.

Что умеет:

Трекинг просмотров страниц через JavaScript-скрипт

Вычисление уникальных посетителей через localStorage

Хранение данных в SQLite

Дашборд со статистикой:

Всего визитов

Уникальных посетителей

Популярность страниц

Посещения по дням

Стек:

Python 3.7+

Flask

Flask-SQLAlchemy

SQLite

JavaScript (для трекинга)

HTML + CSS
